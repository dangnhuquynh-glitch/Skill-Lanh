## Cách cài

1. Tải thư mục skill bạn muốn (hoặc bấm **Code → Download ZIP** để tải cả bộ).
2. Nén riêng từng thư mục skill thành file `.zip` (bên trong có file `SKILL.md`).
3. Vào Claude, mục **Settings → Capabilities → Skills** (tên mục có thể thay đổi theo phiên bản), tải file `.zip` lên.

Hoặc đơn giản hơn: gửi link thư mục skill cho Claude và nhờ Claude cài giúp.

## Tùy biến

Các skill được viết chung chung. Bạn nên sửa lại cho hợp với mình: tên thương hiệu, giờ mở cửa, phần mềm bán hàng, cách xưng hô, nguồn dữ liệu (Google Sheet, Gmail, lịch…).

## Nguồn tham khảo

Nhiều skill được Việt hóa và phỏng theo các dự án công khai. Nguồn gốc ghi ngay đầu mỗi file `SKILL.md`. Khi chia sẻ lại, vui lòng giữ nguyên phần ghi nguồn.
